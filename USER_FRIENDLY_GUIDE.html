ZingTechie UI - Complete User Guide

Purpose

This guide explains how to use the app end-to-end in a simple way.

It is written for day-to-day users, not developers.

Included screens:

  • Dashboard
  • Chat Workspace
  • Sessions
  • Settings
  • Audit & History

1. Quick Start

1.1 Open the app

  1. Open the app URL provided by your admin.
  2. If you are running locally, open:
  • http://localhost:3000/dashboard.html

1.2 Understand navigation

Use the left sidebar to move between screens:

  • Dashboard
  • Chat Workspace
  • Sessions
  • Settings
  • Audit & History

2. Dashboard

What this screen gives you

  • Token status and health
  • Model cache count
  • Prompt and session totals
  • Current session and last used model
  • Recent model usage list
  • Recent prompt history with search and bulk delete

How to use Dashboard

  1. Click Refresh at top-right to reload data.
  2. Review KPI tiles:
  • Token Status
  • Cached Models
  • Prompts Sent
  • Sessions Created
  1. Use Search prompts to find recent prompt text.
  2. Use Select All and Delete Selected in Recent prompts to clean history.
  3. Use Quick Actions to jump to Chat, Studio, or Audit.

Tips

  • If prompt list is long, search first, then bulk delete only what you need.
  • If token status is invalid, go to Settings and update token.

3. Chat Workspace

What this screen gives you

  • Main prompt composer
  • Model selection and comparison
  • Draft save/load/clear
  • Raw text to prompt conversion
  • File attachments and generated test-case prompt support
  • Session save and reuse
  • Conversation view and response inspector

Core flow: send a prompt

  1. Select a model from Model.
  2. Optional: enter System prompt.
  3. Enter your Prompt.
  4. Click Send Prompt.
  5. Review response in Conversation and Response inspector.

Compare multiple models

  1. In Compare models, check at least two models.
  2. Click Compare Models.
  3. Review side-by-side results in Multiple model compare.

Save and reuse sessions

  1. After a useful chat, click Save Session.
  2. Later, use Reuse saved session dropdown.
  3. Choose Load mode:
  • Prompt only
  • Full conversation
  1. Click Load Session.

Work with drafts

  1. Type your work-in-progress text.
  2. Click Save Draft.
  3. Use Load Draft later.
  4. Use Clear Draft when you want a fresh start.

Convert rough notes to prompt format

  1. Paste unstructured notes into Raw text to convert.
  2. Choose Conversion mode.
  3. Click Convert Text.
  4. Review generated prompt content and refine.

File attachments

  1. Click Attach files and select one or more files.
  2. Click Upload Attachments.
  3. Click Generate Test Cases Prompt to auto-build a testing prompt.
  4. Optional exports:
  • Download Test Cases
  • Download Checklist
  1. Use Clear Attachments to reset.

Streaming mode

  • Enable Streaming mode to see response text progressively.

4. Sessions

What this screen gives you

  • Search and sort saved sessions
  • Session message inspection
  • Transcript export in multiple formats
  • Email transcript sharing
  • Rename and delete session files

Find a session

  1. Enter keyword in Search.
  2. Choose Sort method.
  3. Click Apply.
  4. Click any session card to load details.

Export transcript

  1. Select a session from Session list.
  2. Confirm Selected session file is filled.
  3. Enter Export file name.
  4. Choose Format: TXT, JSON, Markdown, HTML, or PDF.
  5. Click Export Transcript.

Email transcript

  1. Select session.
  2. Enter Recipient email.
  3. Click Email Transcript.

Rename or delete session

  1. Select session.
  2. Click Rename File to rename.
  3. Click Delete Session to remove.

Helpful empty-state popups

This screen now shows clear popup guidance when:

  • No session is selected for export/email/rename/delete
  • No sessions match filters
  • No sessions exist on refresh
  • Pagination limit is reached

5. Settings

What this screen gives you

  • Token save/clear
  • GitHub device login flow
  • Model cache refresh and diagnostics
  • App preferences and optimization controls
  • SMTP and email-link base URL settings

Token setup

  1. Paste token in Access token.
  2. Click Save Token.
  3. Use Clear Token to remove it.
  4. Check status in Has token and Token valid.

GitHub device login flow

  1. Click Start Device Login.
  2. Copy User code and open Verification URL.
  3. Complete authorization in browser.
  4. Return and click Poll Device Login.

Refresh and inspect models

  1. Click Refresh Models.
  2. Click Reload Status.
  3. Use Filter models by name or ID.
  4. Review usage guidance and diagnostics panel.

Save app preferences

  1. Set fallback, default sort, and theme.
  2. Set default system prompt.
  3. Configure SMTP host and sender.
  4. Set Public app URL for links in email.
  5. Tune optimization values if needed.
  6. Click Save Settings.

6. Audit & History

What this screen gives you

  • Audit log entries
  • Email history entries
  • Delete controls for single item and all items
  • Clear user guidance when data is empty

Use audit log panel

  1. Click Refresh Audit Log to fetch latest records.
  2. Click Delete on one row to remove only that row.
  3. Click Delete Audit Log to clear all records.

Use email history panel

  1. Click Refresh Email History.
  2. Click Delete on one email row to remove it.
  3. Click Delete Email History to clear all.

Empty-state behavior

If there is no data, popup messages explain the action clearly instead of performing a misleading delete flow.

8. Ready-to-Use Prompt Template Examples

Use these directly in Chat Workspace.

Example A: Summarize code

System prompt:
You are a senior engineer. Summarize code behavior in plain language with risks and edge cases.

User prompt:
Summarize this module, list dependencies, and suggest 3 safe improvements.

Example B: Generate unit tests

System prompt:
You are a test engineer. Write robust unit test cases with positive, negative, and edge scenarios.

User prompt:
Generate unit tests for this function. Include boundary values and failure cases.

Example C: Explain error

System prompt:
You are a debugging assistant. Identify likely root causes and provide a shortest safe fix path.

User prompt:
Explain this error stack trace and give step-by-step fix instructions.

Example D: Release notes

System prompt:
You are a product documentation writer. Produce clear release notes for business users.

User prompt:
Create release notes from these commits grouped by features, fixes, and known issues.

Example E: API test case generation

System prompt:
You are a QA architect. Generate API test scenarios with inputs, expected outputs, and validation points.

User prompt:
Create test cases for POST /api/transcripts/email with success, invalid email, and server-failure paths.

Example F: Incident analysis

System prompt:
You are an SRE reviewer. Provide incident timeline, probable cause, blast radius, and prevention actions.

User prompt:
Analyze this audit and error history and propose prevention controls.

9. Troubleshooting Quick Answers

Token invalid or missing

  • Go to Settings
  • Save token again
  • Click Reload Status

No sessions found

  • Create or save session from Chat Workspace

Email transcript

  • Verify SMTP host and sender in Settings
  • Check recipient format
  • Check Audit & History for email records

Empty delete actions

  • This is expected behavior when list is empty
  • Popup message explains that nothing exists to delete

Model list outdated

  • Click Refresh Models in Settings or Chat
  • Recheck Cached models count
