All Core Features in Your App

1. Dashboard

  • Token/model/session/prompt KPIs and health signals.
  • Prompt history search plus bulk cleanup actions.
  • Quick navigation for daily operations.

2. Chat Workspace

  • Model selection, system prompt, streaming, fallback-aware request flow.
  • Multi-model compare with side-by-side output.
  • Template and prompt history reuse workflows.
  • Draft controls: save, load, clear.
  • Raw notes to prompt conversion helper.
  • Attachment upload with extracted text context and test-case prompt generation.

3. Sessions

  • Create and manage reusable conversation sessions.
  • Search, sort, load modes, rename, update, delete.
  • Transcript export: TXT, JSON, Markdown, HTML, PDF.
  • Email transcript via SMTP configuration.

4. Settings

  • Token save/clear and device login polling flow.
  • Model refresh and cache diagnostics.
  • Fallback toggle, default sort, theme, system prompt defaults.
  • SMTP and public URL settings.

5. Audit and History

  • Audit log list/refresh/delete and clear-all controls.
  • Email history list/refresh/delete and clear-all controls.
  • Governance and troubleshooting visibility for workspace operations.
