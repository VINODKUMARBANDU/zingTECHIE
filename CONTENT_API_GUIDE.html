Content API Guide

Copilot Web UI v3

Base URL: http://localhost:3000
This guide focuses on Chat Workspace content APIs: chat, prompt conversion, attachments, and conversation sessions.

Quick Start

  1. Make sure the server is running on port 3000.
  2. Save token first (UI Settings) so chat endpoints can call provider APIs.
  3. Use POST /api/chat-with-fallback for normal chat flows.
  4. Use POST /api/chat for direct mode and optional stream.

Endpoint Summary

Method Path Purpose Notes
POST /api/chat-with-fallback Main chat endpoint with automatic fallback model selection Requires token and model
POST /api/chat Direct chat endpoint (can stream with stream=true) No fallback wrapper
POST /api/playground/chat Single-model compare/testing chat route Used for compare mode
POST /api/chat/attachments Upload files and extract content snippets for prompts multipart/form-data, files field
POST /api/prompt/convert Convert raw notes to prompt or system+prompt output Requires token, max text length 15000
POST /api/sessions/new Create and save a new chat session Persists messages and model
GET /api/sessions List sessions (pagination and search) Query: page, search, sort
GET /api/sessions/:file Read one saved session file 404 if missing
POST /api/sessions/:file Update saved session content/metadata Updates saved_at timestamp
POST /api/sessions/:file/rename-file Rename session JSON filename Body: newFileName
DELETE /api/sessions/:file Delete session file 404 if file does not exist

POST /api/chat-with-fallback

Best default for Chat Workspace
{ "model": "gpt-4o-mini", "messages": [ { "role": "user", "content": "Create test cases for login" } ] }
Success fields: fallbackUsed, modelUsed, optimization, data

POST /api/chat

Direct mode, supports stream flag
{ "model": "gpt-4o-mini", "messages": [ { "role": "user", "content": "Summarize this bug" } ], "stream": false }
When stream=true, endpoint returns SSE stream.

POST /api/playground/chat

Compare/helper route
{ "model": "gpt-4o-mini", "messages": [ { "role": "user", "content": "Give quick smoke tests" } ] }
Response includes optimization metadata in _optimization.

Attachments API

POST /api/chat/attachments

Upload using multipart/form-data field name: files.

  • Max files per request: 8
  • Max size per file: 10 MB
  • Returns extractedText and promptSnippet per file
curl -X POST "http://localhost:3000/api/chat/attachments" \ -F "files=@C:/temp/spec.pdf" \ -F "files=@C:/temp/screenshot.png"

Response shape: { ok, attachments: [...], limits: { maxFiles, maxFileSizeBytes } }

Prompt Convert API

POST /api/prompt/convert

{ "text": "Raw notes or acceptance criteria", "system_prompt": "Optional existing system context", "model": "gpt-4o-mini", "mode": "system_and_prompt" }
  • mode: system_and_prompt (default) or prompt_only
  • Returns: { ok, system_prompt, prompt, modelUsed }
  • Validation: text is required, model required, text max 15000 chars

Sessions API

Create

POST /api/sessions/new { "label": "Login test session", "model": "gpt-4o-mini", "messages": [ { "role": "user", "content": "Create login tests" } ] }

List

GET /api/sessions?page=1&sort=newest

Read/Update/Delete

GET /api/sessions/:file POST /api/sessions/:file DELETE /api/sessions/:file

Rename File

POST /api/sessions/:file/rename-file { "newFileName": "release_login_suite.json" }

Error Reference

Status Typical Error Meaning
400 No token saved Token must be configured before model calls
400 model is required Request body missing model field
400 text is required prompt/convert called without text
400 File too large / Too many files Attachment limits exceeded
404 Session not found Session file does not exist
409 A session file with that name already exists Rename collision on target filename
